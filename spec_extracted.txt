PROGRAM ZA MALOPRODAJU (specifikacija)
O Aplikaciji opcenito
Zelim da napravimo program za maloprodaju, veleprodaju i materijalno knjigovodstvo. Zelim web based aplikaciju koja se sastoji od dva git projekta: java spring boot back-end i angular material design fron-end i da koristi postgres sql database. Koristi code first princip za kreiranje tabela u bazi iz entiteta. Svaki entitet mora imati nasljedjenu klasu za sys_created_date, sys_modified_date, sys_modified_by, sys_created_by i da se unose podaci na unos i update korisnika u tabeli. 
Zelim napraviti modernu web aplikaciju sa glavnim top taskbar manijem u kojem ce postojiti izbornici i koji ce se pojavljivati role based na osnovu role prijavljenog korsnika. 
Login forma za prijavu korisnika prema razlicitim ulogama (administrator, korisnik, knjigovodja, menadžer, blagajnik). Svaka od uloga ima različite izbornike i svakom korisniku se mogu dodijeliti određeni izbornici. Koristit jwt token i refresh tokem tako da se uradi logout nakon 1h neaktivnosti, a sesija se produzava ako je korisnik radi u aplikaciji.
Arhitektura aplikacije treba da podrzava da svaka kompanije ima listu poslovnica, a svaka poslovnica ima listu korsinika. Svaki korisnik zavisno od uloge ima listu izbornika, s tim da administrator u kompaniji ima pregled liste svih poslovnica i moze praviti izvjestaje/preglede za poslovnicu ili za sve poslovnice iz kompanije. Kod spremanja podataka u bazu obavezno navesti id kompanije, id poslovnice i id korisnika radi lakseg indeksiranja izvjestaja.
Kod prikaza podataka u tabeli prikazi uvijek podatke za tekuci dan (racuni) ili godinu (dokumenti, fakture)
